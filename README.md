# Sitema de Reuniões

### Descrição do Projeto 

Este é um projeto no qual foi desenvolvido para fins academicos.

O seguinte projeto consiste em uma aplicação no console (Console Aplication), desenvolvido em **C#** e utilizando o **.NET 8.**

A função do projeto é realizar o gerenciamento e reserva de reuniões em uma empresa. Podendo cadastrar uma sala, reservar um horário, mostrar as salas e excluir.

## Tecnologias do Projeto

- C#
- .NET 8
- SQLite Local
- Entity Framework Core

## Executando o Projeto

É necessário ter o **SDK** do **.NET 8** instalado;

Após isso, atravez do link do repositório, clone para sua maquina local utilizando o camando **"git clone"** no terminal;

Execute o código usando o comando **"dotnet run"** no terminal do projeto;
